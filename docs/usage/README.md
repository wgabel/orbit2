The pitch-only sequencer is not a Note/Gate/velocity source. Dedicated analyzer sinks, user-defined reusable composite library/macros, compact modal bank, standalone pitch shifter, polyphony and sample assets remain planned or partially delivered as described in the [roadmap](../../ROADMAP.md). The searchable nested outline is implemented. Do not infer availability from design-only PRs. Documentation PRs [#22](https://github.com/wgabel/orbit2/pull/22), [#24](https://github.com/wgabel/orbit2/pull/24), [#26](https://github.com/wgabel/orbit2/pull/26), [#29](https://github.com/wgabel/orbit2/pull/29), [#33](https://github.com/wgabel/orbit2/pull/33) and [#38](https://github.com/wgabel/orbit2/pull/38) provide musical guidance, not new audio nodes or presets.

For agents, read the relevant technical module and confirm the actual node registry, parameter definitions, editor controls and tests when exact patch JSON or implementation behavior matters. A feature usage update should identify its real implementation PR, a reproducible example, expected behavior, common mistakes and remaining limitations. Keep the usage index brief; put detailed contracts or additional examples where they are easiest to discover.

**Planned, not yet available:** [stereo audio, panning and oscillator unison](../audio/stereo-panning-and-unison.md) (Phase 7.5) documents the proposed controls, compatibility policy, routing examples and sound recipes. Performance monitoring and a benchmark baseline (Phase 7.3) should be implemented first; do not create patches with proposed port or parameter keys.
