##### Keyboard performance and continuous pitch sequencer (Phase 7.2.8 — partial)

**Implemented 7.2.8a — live continuous pitch.** Add **Note Sequencer** (`generator.note-sequencer`), set its Reference note (default A4/MIDI 69), and connect its Pitch output at unity to the Pitch sockets of free oscillators with Semitones tracking enabled. For a bank tuned around 110 Hz, set A2/MIDI 45 as reference; the A2 key is unison and A3 doubles all tracked base frequencies. Initial pitch (default 0 st) applies before the first key and after Reset pitch. Select the node header and click Arm keyboard in the shared toolbar. The on-screen piano and physical A S D F G H J K / W E T Y U keys share a validated note-on/off contract; Z/X change octave. The octave and available keys respect MIDI 0–127 and the receiving ±60 st offset range. Key release never resets the latch. Text/slider/select editing, dialogs, modifiers, auto-repeat and disarmed input are excluded. Changing selection, navigation or stopping playback disarms capture; blur/visibility loss clears held codes without resetting pitch. The live offset is measured from the current DSP meter, not guessed from the last UI key. Five reference/starting-offset presets use the ordinary catalog and persistence; no transient target or octave state is serialized. Implementation: [PR #16](https://github.com/wgabel/orbit2/pull/16).

Each reachable Note Sequencer reserves one lane in the existing bounded manual action worklet manifest (30 combined sources, 64 queued commands per lane). Values 1–128 encode MIDI note + 1, 129 explicitly resets to Initial pitch, and zero is no event. The Faust evaluator latches note number at the action sample, emits `clamp(note - reference, -60, 60)` or Initial pitch, and reports a passive graph-qualified pitch meter. MIDI note-on actions reject out-of-range, disconnected, stale, inactive or busy targets; note-off is a no-op in this mode. The host preserves accepted pitch codes for compatible reachable nodes across structural voice replacement by seeding the new worklet lane before its first render; removal or root stop retires that transient state. Ordinary note changes do not modify the editable graph, revision, history, base parameters, playback generation or oscillator phases/effect state. Host-message latency is not scheduled sample accuracy; accepted internal action transitions are sample-aligned. Quantized live recording is implemented in the 7.2.8c PR below; Note-mode articulation remains 7.2.8d. No gate or trigger output is exposed yet.

**Implemented 7.2.8b — pitch patterns, long transport and glide.** Select the Note Sequencer and open **Edit pattern**. Choose Live or Loop, 1–64 steps (default 16), synchronized quarter-beat divisions multiplied by 1–64, or Free seconds (0.01–600 seconds per step). Glide is a linear semitone ramp, 0–600 seconds, sampled at a new pitch target; an interrupted ramp retargets from its current value. The grid keeps the edit cursor distinct from the measured playhead. Select a slot and choose a MIDI note or Hold; optionally enable Step entry and Arm keyboard to enter notes and advance by 1, 2, 4 or 8 slots. Space enters Hold; arrows move the cursor; wrap is automatic. Shrinking retains hidden slots. Clear all requires confirmation and is one undoable graph command. The slow-drone and quarter-note pattern presets are ordinary named node configurations. Implementation: [PR #17](https://github.com/wgabel/orbit2/pull/17).

The schema-1 fixed-capacity payload uses stable keys `pattern-step-01` through `pattern-step-64`, zero = Hold, 1–128 = MIDI + 1, and bounded timing/count/glide/mode controls. Complete pre-pattern sequencer patches and presets migrate to Live and 64 Holds without changing existing IDs. Imports with malformed or missing partial slot data are rejected. Pitch values remain clamped relative to the current reference. Pattern controls are not duplicated as 64 sliders in the node frame. Runtime pattern values are immutable snapshots sent as a single lane update at the next render quantum, not Faust structural controls. The scheduler evaluates the current slot on activation, timing/mode edit, reset or seek, looking back to the most recent populated step when applicable instead of replaying missed events. Slot-only edits (including a committed take) become active at subsequent step boundaries, rather than replaying the onset of the current step. Ordinary Holds emit a playhead update without a pitch change. Live keyboard input can override a running loop until the next populated step; switching Loop to Live holds the last pitch.

The existing transport worklet now additionally publishes split whole/fraction beat and elapsed-second positions plus reset identity, preserving the original wrapped phase and reset channels for legacy nodes. Both loop modes anchor to transport zero, freeze/resume with root playback, and reset to step one on Reset transport. Tempo changes do not affect elapsed seconds; synchronized loops preserve musical position. The action adapter consumes the extra clock channels internally, keeping the original 30-lane and 32-channel DSP limits. Its scheduler sends combined integer step/note codes (step × 256 + action, step 65 denotes Live) to the Faust latch, which reports a measured 1-based playhead and ramped offset. Timing uses double-precision modulo across split positions; whole-position channels are exact up to 2^24 beats or seconds. Full patterns are applied without graph compilation or carrier phase restart. A replacement derives the active nonempty pitch from the shared clock; arbitrary DSP state transfer across structural replacement is not promised.

**Implemented 7.2.8c — quantized live recording.** Select the Note Sequencer, open Edit pattern, choose Loop and a step count/timing, play the connected patch, arm the keyboard and disable Step entry. Choose Overdub (retain existing slots) or Replace active slots (start with Holds; retain hidden slots) and a quantization spacing that divides the active step count. Record take creates a transient `PitchRecordingTake`; the pending grid previews notes while normal live pitch monitoring continues. Each admitted note-on reads a fresh running audio-clock transport position through `IMusicalTransportService.ReadPlayingPositionAsync`, independent of UI telemetry, and only accepted performance actions are recorded. This timestamps host admission, not the exact physical strike or the rendered sample. Nearest compatible boundary wins, ties go forward, wrap is modulo the loop, and later accepted note-ons replace earlier notes in the same slot. Free patterns use elapsed seconds; synchronized patterns use beats, including long loops and tempo edits. No release inserts a Hold. Reset/clock replacement, pattern/reference changes, navigation, disarm or playback stop invalidate the take. Commit take verifies the original pattern/reference and live transport generation, then issues one existing `SetPitchPatternStepsCommand`; Cancel discards only the draft and never rewinds audible live pitch. The pending take is not passed to the worklet, autosaved or added to graph history. Committed slot changes take effect at future step boundaries; there is no overdue-note replay or per-note compilation. Undo/redo and patch export/import reuse the ordinary pattern persistence contract. Implementation: [PR #19](https://github.com/wgabel/orbit2/pull/19).

**Worked live take.** Route the sequencer Pitch at unity to the three pitch-tracked oscillators of the slow-drone example below. Set reference A2, 16 steps, a quarter-beat step and quantization every four steps; choose Replace active slots, start playback and Record take. Play A2, D3, E3 and A2 near the four beat boundaries, then Commit take. The resulting four occupied slots are 1, 5, 9 and 13; the intervening Holds preserve pitch. For a four-step ambient take, use Free 20 seconds, quantization every step and 4-second glide. Switch to Overdub to replace individual notes in a subsequent pass. Cancel is safe and Undo restores the entire previous committed pattern. Optional count-in/metronome, explicit Note-mode duration/velocity and gated articulation remain future work.
