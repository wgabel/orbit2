# Orbit 2 — agent entry point

These instructions apply to all repository tasks, including read-only research, planning, code review, implementation and delegated work.

Before substantive work:

1. Read the [canonical contributor instructions](docs/agents/contributor-instructions.md).
2. Use the [documentation map](docs/README.md) and follow the applicable task routes. Read the required contracts and relevant sections before making decisions or changes.
3. For nontrivial implementation, follow the [work-slice protocol](docs/agents/work-slices.md) and locate the relevant [roadmap](docs/roadmap/overview.md) entry before coding.

Apply the canonical contributor rules throughout the task, including verification and documentation feedback. If scope changes, consult additional applicable documentation. Each delegated agent must follow this entry point; a coordinating agent must explicitly provide it when the tool does not discover it automatically.

Do not bulk-load unrelated docs. If required documentation is inaccessible, report the limitation rather than claiming compliance or proceeding with affected changes.

This file is a discovery entry point, not a copy of the detailed policy.
