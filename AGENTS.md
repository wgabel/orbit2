# Orbit 2 — agent entry point

For every Orbit 2 request (including read-only questions, short follow-ups, research, planning, review and delegated work), first read the [canonical contributor instructions](docs/agents/contributor-instructions.md) and complete the [mandatory initialization protocol](docs/agents/contributor-instructions.md#mandatory-initialization) before substantive work.

Apply its [repository-first response policy](docs/agents/contributor-instructions.md#repository-first-response-policy) before relying on conversation memory or answering. Follow its documentation routes, scope-change and delegation rules, verification policy and handoff requirements. Do not load unrelated documentation.

If this entry point is not automatically discovered, the coordinating agent must explicitly provide it. This file is a discovery entry point, not a second copy of the detailed policy.
